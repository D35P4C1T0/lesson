# Links

Eight resources covering the four lesson sections. Start with the articles, use the tutorials for examples, and watch the videos for visual explanations. The older videos are for concepts; use the documentation for current commands.

## Articles and insights

| Topic | Resource | Why it is useful |
|---|---|---|
| eCREAM | [Official project website](https://ecreamproject.eu/) | The research purpose and context behind the application. |
| Architecture | [Backends for Frontends — Microsoft](https://learn.microsoft.com/en-us/azure/architecture/patterns/backends-for-frontends) | Explains the role of the BFF beside the dashboard example. |
| OpenAPI | [Introduction — OpenAPI Initiative](https://learn.openapis.org/introduction.html) | Explains why an API contract is useful before introducing syntax. |

## Tutorials

| Topic | Resource | Suggested use |
|---|---|---|
| OpenAPI | [Content of message bodies](https://learn.openapis.org/specification/content.html) | Connect the patient JSON response to its schema. |
| Kubernetes | [Learn Kubernetes Basics](https://kubernetes.io/docs/tutorials/kubernetes-basics/) | Work through deploying, exploring, exposing and scaling an application. |

## Practical tool

[Swagger Editor](https://editor.swagger.io/) — open the local [patient-api.yaml](examples/patient-api.yaml) to explore its operation and schema. The example does not include a running server.
